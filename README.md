## The Problem

Selling digital products often requires complex payment handling, multi-currency support, and robust admin tools. Most solutions are either too expensive or lack flexibility.

**Nexus** provides a complete, production-ready e-commerce platform tailored for software and digital products.

---

## Key Features

| Feature                    | Description |
|---------------------------|-------------|
| **Dual Payments**         | Razorpay + Stripe integration |
| **Multi-Currency**        | Support for multiple currencies |
| **Admin Portal**          | Full management dashboard |
| **Product Management**    | Easy upload and management of digital products |
| **Modern UI**             | Built with Tailwind CSS v4 and Framer Motion |

## Tech Stack

| Layer            | Technology                          |
|------------------|-------------------------------------|

| **Payments**     | Razorpay + Stripe                   |
| **Styling**      | Tailwind CSS v4 + Framer Motion     |
